# 右端爆発の対象寸法拡張と行情報の容量比較

60fps維持は未達。素材・全1,492寸法・通常クロックを保持し、配布ROMは更新しない。幅91以上だった逆順native描画を88、85、82へ広げたが、道中の表示遅れは改善しなかった。

|道中800フィールド|logic/表示|実PPUを含む画素一致|表示間隔フィールド数:回数|最大SA-1時間|
|---|---:|---:|---|---:|
|従来の幅91・v5（既存比較）|656/645|168|1:638、2:4|22.778591ms|
|幅88・8byte行情報|656/645|168|1:638、2:4|22.770955ms|
|幅88・hint圧縮|655/644|168|1:636、2:5|22.770955ms|
|幅85・6byte行情報|656/645|168|1:638、2:4|22.766392ms|
|幅82・6byte＋hint圧縮|655/644|168|1:636、2:5|22.772725ms|
|上記＋全体が見える行のhint解読を省略|655/644|168|1:636、2:5|22.772725ms|

幅88の6byte版は境界fixtureのみで、道中の性能値はない。全11試験は末尾停止なし。ゲームの共通logic世代のpacketも配布固定map版と一致する。表示間隔は初期2枚を除外し、起動準備を含む表示数を800で割ってfpsとはしない。

行情報は従来の8byteから6byteへ詰める。コードとhintの下位16bit、偶数origin/extent、最大16種のコードbank番号、hintのDF/FE bank選択を保持する。値の範囲・偶数条件・bank数をビルド時に検査し、画像や寸法を省略して収めない。selectorは最大64項目を置ける範囲へ広げ、bank表とnear画像の固定領域DF8000..91FFとの非重複を検査する。

右端hint圧縮は命令offsetを3byte単位へ変換し、8項目ごとのcheckpointと減少量0/1/2/4の2bit差分を使う。短くならない表は非圧縮の単位値を置く。幅88ではhintが7,973→4,130bytes、全行情報は27,143→23,300bytes。6byte行情報だけなら22,399bytesで、境界fixtureの最大時間も8.843395msと8byte版8.843488msとほぼ同じだった。圧縮版は9.644707msへ増え、容量削減を速度改善と扱わない。

幅85の6byte版は行情報26,243bytes。幅82の6byte＋圧縮版は24,028bytesで、hint自体は9,236→4,826bytes。全体が見える行で解読を省く追加経路は境界fixtureを9.918206→9.700860msへ短縮したが、道中の表示間隔は変わらない。

境界fixtureは各348画面が実PPU・VRAM・paletteを含めて全画素一致。表示済みmetaから、幅88の高さ68/69、幅85の高さ66/67、幅82の高さ64について、素材40/41×横中心13位置×上端7位置の全組み合わせを確認した。幅88/85は各364ケース、幅82は182ケース。短いfixtureだけの1フィールド表示をゲーム全体60fpsの根拠にはしない。

静的検証は元ROMに対する全1,492寸法、native行90,854回、弾の行158,688回を照合する。幅82版は逆順2,430kernelの全88,204右端境界、左端6,326kernelの190,929ケースが一致。6byteレコードから復元したcode pointer・origin・extentも、実ROMの元のnative行へ照合する。

幅79の6byte＋hint圧縮版は、native/左hintのpayloadEnd=8,313,425に達した後、右端の行情報用領域が不足してビルドを完了しなかった。未完成版の性能値はない。失敗ログを保存し、buildは検証済み幅82・省略経路版へ再ビルドして戻した。今後は既存native行にあるpointer/位置を別表へ重複保持しない方式などを検討する。幅79以下を削除して達成扱いしない。

検証ホストのPython 3.10と計測専用Mesenについて、Windows Application Errorにアクセス違反0xC0000005の記録があった。ユーザーのMesenは操作していない。別のPython 3.12環境で静的検証を再実行し、幅82/85の試験も完走した。アクセス違反の根本原因や完全解決は断定しない。失敗したホスト実行をROMの性能値へ混ぜない。

再現コマンドはcommands.json、集計と証拠ファイルSHAはcomparison.json。tools/report_sa1_reverse_widths.pyが6つの証拠zipへ各ROM・labels・manifest・静的照合結果・全画素照合用データを保存する。公開ROMのSHAは9934d77b85913187be8d3ebd8315f854718eb24b08492204ce8b3288f620146cのまま。
