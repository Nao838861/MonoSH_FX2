# 描画命令の準備だけをSA-1へ移す試験

ゲーム更新と自機OBJは本体CPUへ残し、描画命令のOBJ除外・安定ソート・
カラー弾寸法変換・コピーをSA-1へ移した。元の素材と命令の意味を維持する。
本体から生のdrawをBW43:1000へ送り、SA-1が従来と同じBW43:0000へ出力する。
完了した命令数を本体の転送記録へ回収する。

`--packet-offload`はROM実行、`--packet-iram`追加はコードを内部RAMへ置く。
`--packet-iram-arrays`ではorder・key・linkも内部RAMへ置き、
コードと配列を合わせて952byte（0300..06B7）とした。
ほかの描画コードも同じ内部RAMを使うため、仕事ごとに読み込み直す。

| 条件 | field | 表示枚数 | 画素照合 |
|---|---:|---:|---:|
| ROM・道中 | 800 | 703 | 129 |
| ROM・道中長区間 | 1,800 | 1,683 | 146 |
| 内部RAMコード・道中 | 800 | 703 | 129 |
| 内部RAMコード＋配列・道中 | 800 | 703 | 129 |
| 内部RAMコード＋配列・道中長区間 | 1,800 | 1,683 | 146 |
| 内部RAMコード＋配列・ボス長区間 | 1,800 | 1,669 | 145 |
| 内部RAMコード＋配列・反転・色・四辺clip | 232 | 121 | 120 |

従来最良の道中1,689枚を下回った。内部RAM化後も道中の2field間隔は28回、
ボスは41回残るため採用しない。60fps未達。

内部RAM上のラベルは後続の別JITコードともアドレスを共有する。
最初の配列版では計測callbackが後続コードにも反応したため、
sa1_packet_prepareからsa1_packet_finishedまでだけソート検査を有効にした。
修正版の全試験では安定ソート検査と完成画像の照合が通った。
ROM実行版の709世代の出力packetは従来版とbyte単位で一致した。

結果はcomparison.json、実行ROM・ラベルと捕捉画像・計測原データはevidence.zip。
公開試遊ROMは更新していない。
