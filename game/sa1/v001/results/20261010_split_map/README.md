# マップの低・高byte分離試験

表示対象736タイルのマップを、低byte 736Bと高byte 736Bに分離した。
低byteは全量、高byteは転送先ページの旧世代と新世代で上位タイル番号が変わる範囲だけ転送する。
高byteがすべて$24の序盤は、マップ転送が1,472Bから736Bへ減る。
各ページの旧範囲を保持し、$25から$24に戻るタイルも更新する。

`--split-map-dma`が逐次書き込み版、これに`--split-map-mvn`を足すと
番号列のROM表からMVNでまとめて書き込む。元の画像・パレット・生バッファは変更していない。
いずれも独立した試験オプションであり、既存の公開ROMは更新していない。

| 試験 | フィールド | 表示枚数 | ピクセル照合枚数 |
|---|---:|---:|---:|
| 逐次書き込み | 800 | 704 | 129 |
| 逐次書き込み・長区間 | 1,800 | 1,686 | 146 |
| MVN書き込み | 800 | 704 | 129 |
| MVN書き込み・長区間 | 1,800 | 1,688 | 146 |

最良の既存構成は1,800フィールド中1,689枚。転送量削減だけでは表示枚数を改善できず、
60fps達成とは扱わない。比較結果と原データ・両ROM・ラベルは`comparison.json`と`evidence.zip`。

MVN版800フィールドの初回Python画像照合で`ValueError: generator already executing`が発生した。
エミュレーション自体は完走しており、同じROM・ラベルで保存済み全129枚を再照合し一致した。
この再照合済み結果を保存している。
