# 裏面との差分比較で削減できる転送量の上限

既存full192 ROMの654世代分のpackedフレームバッファを使い、現在と二世代前の占有集合から「32 Bの画素が完全に同じタイル」を除いた場合の転送量を再計算した。新しいROMの速度測定ではない。60fpsは未達。

重い530〜570世代の転送対象10,189タイル中、同じ画素だったのは445タイル（4.37%）。削減できるのは平均347.317 B/世代で、画素比較・マスク変更・転送記述子再構築の処理時間は含まない。

| 世代 | 現在の転送量 | 同一画素を除いた転送量 | 削減 |
|---|---:|---:|---:|
| 543 | 10,400 B | 10,016 B | 384 B |
| 546 | 11,744 B | 11,296 B | 448 B |
| 549 | 11,648 B | 11,232 B | 416 B |

元の占有集合から計算した転送量・記述子数・費用は、前回の診断と全対象世代で一致する。最大48記述子に収めるための隙間拡張も含む。比較順序を変えた場合の16bit読取回数も記録したが、実命令の実行時間ではなく、画素比較を追加する方式の速度改善を証明するものではない。

`tools/probe_sa1_fixed_back_pixels.py`はcommit済みの`20261013_transfer_deadline/evidence.zip`と`20261013_flip_prepare/evidence.zip`を読み、`comparison.json`を再生成する。buildディレクトリやホスト側の新規描画には依存しない。元データのSHA-256を結果に記録している。
