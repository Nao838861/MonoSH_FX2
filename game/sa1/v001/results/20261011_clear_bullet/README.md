# 消去待機と敵弾の画面内経路

全件800フィールド・168画面一致・実PPU参照確認済み。固定配置版との描画packetも一致した。

| 試作 | 表示枚数 | 2フィールド間隔 |
|---|---:|---:|
| PPUがDMAを要求中なら、命令消去せず転送完了後にSA-1 DMA消去 | 645 | 6 |
| 画面内の敵弾で行ごとの座標・端の判定を省略 | 646 | 5 |
| 可変長VRAM・統合配置表生成と画面内敵弾の組合せ | 642 | 6 |

最良の固定配置版647表示・待ち4回を上回らず、公開ROMへ未採用。60fps維持は未達。開始準備を含む表示枚数をfpsへ換算しない。

画面内判定は右端2画素を保守的に除外し、4画素単位のwordが画面外へ書き込まない条件にした。上下の範囲が全て画面内なら行アドレスを128byteずつ進める。IRAM 019Eを使うため、同じ領域を使う二面変換との併用を禁止する。

最初の敵弾高速経路テストはビルド終了前に開始してしまったため停止し、v2で測り直した。v1を比較の証拠には使わない。

再現はcommands.json、記録と画素・PPUの証拠はevidence.zip。公開ROMはSHA256 9934d77b85913187be8d3ebd8315f854718eb24b08492204ce8b3288f620146cを維持する。
