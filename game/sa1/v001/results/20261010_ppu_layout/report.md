# PPU参照位置の修正と再検証

従来の検証器は、意図したVRAM配置から画像を復号していた。PPUの実際のCHR・配置表の開始位置を確認しておらず、固定配置表とVRAM四面の不整合を見逃した。過去の固定map・map差分・四面の画素一致を正常表示の証拠として扱わない。60fps達成には至っていない。

固定mapは、配置表の開始位置BC00が2KiB整列を満たさず、遠景のCHR開始位置も8KiB整列を満たしていなかった。修正版はBG1配置表C000、遠景CHR開始A000、遠景配置表の使用部分C600/CE00、自機C800へ配置する。草・遠景の126tileは既存画像をそのまま移し、地面D000..E8EFと地面配置表F000..FFFFを維持する。

四面ではCHR開始位置のシフト量とBG2の指定が誤り、12KiBページの奇数面に必要なタイル番号128の補正も欠けていた。修正コードは同時に追加するが、四面の採用には修正後の別試験が必要である。

検証器は各捕捉世代でMesenのPPU状態を保存し、BG1/BG2のCHR・配置表の参照位置を照合する。VRAM画像の復号にも実際のCHR開始位置を使用する。道中・ボス・反転四辺・爆発区間の4試験と修正ROMをevidence.zipに保存する。表示世代の順序、非表示期間内のDMA、遠景・草・地面・自機・パレットの従来検査も継続する。

道中1,900fieldで1,743枚、ボス1,900fieldで1,741枚を表示した。起動後に2field間隔となる箇所はそれぞれ8回・9回残る。起動期間を含む総枚数だけでfpsを判定しない。試遊ROMはこのPPU修正版へ差し替える。
