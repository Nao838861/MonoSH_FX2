# 配置表専用BW-RAMで退避DMAを省く

固定map差分を現在の正しいPPU配置で再測定したが、CPU直接更新639表示、DMA区間更新640表示で、公開版647表示を超えない。旧試験の誤ったPPU配置を速度・表示の証拠に流用しない。今回は168画面を実PPU参照位置から照合した。

|方式|800fieldのlogic/表示|2field間隔|画素一致|
|---|---:|---:|---:|
|公開固定map版（既存比較）|654/647|4|168|
|固定map差分・CPU直接更新|646/639|10|168|
|固定map差分・DMA区間更新|647/640|10|168|
|FIFOのmap記入と初期化fallbackを展開|653/642|6|168|
|専用BW配置表12枠＋展開|656/645|4|168|
|専用BW配置表＋広幅消去の閾値32|655/644|5|168|

固定map直接更新版には0/3field間隔も残る。全方式で均等60fpsは未達。共通logic世代の描画packetは公開比較版とbyte単位で一致し、素材・物量・更新内容を削っていない。起動時間と先行保持枚数が異なるので表示枚数だけをfpsへ換算しない。

`--vram-fifo-fast-fill`はSA-1のmap初期化fallbackをDB切替＋32word展開、map区間記入を8word展開にする。BW版は`--vram-fifo-map-bw`で各recordに専用の1472B配置表を持たせ、CHR転送完了後にrawを再利用しても配置表を維持する。従来のBW→WRAM退避DMAは不要になる。

専用表はbank40/41/42の6C00、71C0、EC00、F1C0へ置く（12枠）。各rawの先頭0400/8400、192行の画像、累積費用表6A00/EA00付近の後ろを利用する。描画の下側余白は208行末までに制限し、209行目以降へ直接描かない。リンク後の実アドレス表で、全rawの描画範囲、累積表、12配置表の非重複をassertする。初期版は800fieldの168画面が一致したものの、従来の248行末までの余白が将来の配置表を壊し得るので除外し、修正版v2を保存した。

専用表版は従来FIFOの6待ちを4待ちへ減らしたが、公開版を上回っていない。公開ROMは変更しない。次の検討対象はrawの消去帯の間にある空白を飛ばす方法。負荷集中41画面で実画素の占有タイルは平均6844B、各帯の最小最大を結んだ範囲は9593B（理想的な差は約29%）。細分化の設定費用をまだ含まないので、消去の実装と実測が必要。
