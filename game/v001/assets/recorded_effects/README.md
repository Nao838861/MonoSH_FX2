# 録画由来の自弾と二層遠景

2026年10月9日、前回の距離別配色を訂正し、全自弾をゲーム全体の論理時間で同期して変色させる。4更新ごとに水色→薄緑→黄緑→黄色、16更新周期。周期長は仮設定で、距離・サイズ・反射によって色を選ばない。色の見本は `shot_color_reference/`、四組のRGB5と時間仕様は `bullet_color_phases.json`。元の `bullet_palette.json` はindexを解釈する抽出時の見本として保存。OBJ用160bytesは起動時だけ転送し、時間色は描画世代ごとのOAM属性で選ぶ。CHR・毎フレームのDMA量は同じ。[結果](../../RESULTS_20261009_GROUND_TIME.md)。

山と森林の上端・下端の誤った削除は取り消し、元RGBAの全画素を表示する。BGの縦座標は2ドット下。削るのは奥行きのある地面の画面上端2行で、元の投影位置104を基準とする計算は保ち、見える地面だけ106行からにする。`source.json` の `sceneryDisplay` と `build_ground.py` がこの設定を保持。現在の遠景共用CHRは203タイル。

原本は `D:\HomeBrew\MonoSH\tmp\スペースハリアー録画１.mp4`。動画は同梱しない。切り出し位置・フレーム・原本SHA256は `source.json` に保存した。

`bullet_capture.png` は78.100秒の実画素。`bullet_source.png` は自機に隠れた輪を対称補完した画像。中央は露出した発光芯の実色で補った。完全に遮蔽された画素を無損失で取り出したとは扱わない。`bullet.png` は56×32、透明0＋最大15不透明色のindexed PNG。パレットはSNES RGB5。旧 `obj_color/10.png` は以前の黄色い弾の記録として残るが、現在のカラーOBJには使わない。

発射直後の56×32は32×32 OBJ二枚、40×24は32×32一枚＋16×16二枚、32×20は32×32一枚。以降24×16、16×12、12×8、10×6、8×6、6×4、4×4、2×2、1×1へ縮小する。論理上の寿命・当たり判定・弾数は維持する。反射弾は12×8を使い、発射直後の大きな輪と区別する。

自機17ポーズの16×16部品を共用し、全縮小絵と合わせてOBJ用16KiBの126枠・16,128byteに収めた。画像のDMAは起動時だけ。毎画像のOAMは前回と今回の使用枠の大きい方まで送り、消えた弾の枠も確実に隠す。high OAMは32枠分の8byteを送る。

`far_source.png` / `near_source.png` は58.000秒の紫の山／緑の森林を色で分離した透明画像。録画の256px区間を反転して512px周期へつなぐ。別の角度を新しく描き足した画像ではない。`far.png` / `near.png` は各タイル最大3不透明色、各BGに8パレットを割り当てた2bpp版。二枚で共有するCHRは203タイル・3,248byte。

BG4は紫の山、BG1は森林、BG3は地面、BG2はFXの敵・物体。BG2のタイルを高優先にして、森林で敵を隠さない。森林の横スクロール速度は紫の山の2倍。空は録画の21行のRGB5色を間接HDMA6でCGRAM0へ送り、カメラ高さに応じて開始位置を変える。
