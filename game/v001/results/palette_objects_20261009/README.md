# FX2の物体だけを黒背景で共通16色へ減色

2026年10月9日。ユーザーの原文：

> 木が壊れているので、背景をくりぬいて真っ黒か、黒に近いどれかの色にして、地面と山を消した画像で16色化してみて。FX2が描くものだけで16色にすべきだ。ディザは意味がないのでやめて。

録画86.5秒からボスと炎の光弾だけを抽出し、空・山・地面・影・HUDを除去した。自機は現在のカラー4bpp版で専用OBJパレットを使うため、この共通パレットの対象から除く。自機に重なる輪は隠れた元画素を採取できないため含めない。追加物体は38秒のザコ、32.133333秒の通常弾三発、50秒の木、77秒の爆発。

木の切り抜きは、緑という条件だけで葉と地面を一緒に拾わないように見直した。葉の彩度、茶色い幹、隣接する暗い輪郭を分離し、葉の内部の陰影を保持する。不透明な画素のRGBは録画の元矩形から変更しない。木の比較画像の右列は、他の物体との重なりが入らないように木単体を同じ共通パレットへ写した結果。

## パレットの条件と結果

パレット学習は**不透明物体の17,180画素だけ**を対象とし、黒背景の面積を含めない。Median Cut（Pillowの`kmeans=20`指定）で15色を作り、SNESのRGB5へ丸める。index 0は純黒、index 1～15は物体用。各物体を同じパレットへ最近色で割り当てる。ディザ処理は行わない。

PNGは黒背景として保存する。背景index 0を透明として扱える構成にし、物体内の暗い画素は非ゼロindexへ割り当てる。全体の実使用16色、不透明物体の15色、RGB5で表現できる色だけであること、背景が全て純黒であること、背景と不透明画素のindexが混ざらないことをassertした。

背景込みの前の試験で平坦になった木は、この試験では明暗の緑が残る。ボスの鱗・腹、爆発の模様も保持できる。一方、通常弾の青・紫などはこの共通パレットでも色の近似が残る。これは一枚の物体合成画像での比較であり、全ステージ・全アニメーションのパレット評価やROMの更新ではない。

## 再生成

```powershell
python -X utf8 tools/probe_16color_objects.py
```

元動画の別の保存場所は`--video <パス>`で指定できる。ffmpeg、Pillow、NumPyを使う。背景込みの以前の比較は`../palette_composite_20261009/`に履歴として残す。今回の生成経路にディザはない。
